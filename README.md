# 🌍 3D Map Globalizer

Proyecto experimental para convertir mapas planos en **globos 3D interactivos**.  
La idea es tomar mapas de videojuegos, novelas o mundos ficticios y proyectarlos sobre una esfera para poder explorarlos de forma más inmersiva.  

⚠️ **Nota:** Este es un proyecto en desarrollo y gran parte del código inicial fue generado con herramientas de IA. Lo estoy utilizando como base de aprendizaje y práctica.

---

## 🚀 Características actuales
- Renderizado básico en 3D de un mapa sobre una esfera.  
- Control de cámara para rotar y explorar el globo.  
- Arquitectura inicial pensada para poder cargar mapas personalizados.  

---

## 🛠️ Tecnologías utilizadas
- **JavaScript**  
- **Three.js** (librería de gráficos 3D en WebGL)  
- **HTML + CSS**
